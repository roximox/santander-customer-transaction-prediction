# Individual Logbooks

Each member maintains an individual, chronological Logbook in their assigned
directory. Write entries soon after completing the work; do not reconstruct
them artificially at the end of the project. Time records must reflect the
actual time spent, and each member is responsible for the accuracy of their own
content.

Use this filename convention:

```text
YYYY-MM-DD_ticket-short-title.md
```

Example:

```text
2026-07-25_ADA-SETUP-01_initial-project-setup.md
```

Where applicable, an entry should reference the sprint, ticket, meeting,
branch, pull request, notebook, script, figure, table, decision, difficulty, and
adaptation associated with the work. Document abandoned approaches as well as
successful ones. Together, the entries should make the project workload
plausible and auditable.

The directories `member_01` through `member_04` remain stable so references and
automated checks do not depend on personal names. Each README identifies the
responsible member, and each member edits only their assigned directory.
